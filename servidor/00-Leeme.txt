Servidor ProyectoBiometria
Nombres al estilo plantilla del profe + Sprint 0 Ferran (PHP/XAMPP).

Estructura (como la del profe):
  servidor/
    bbdd/           datosMediciones.sql
    logica/         Logica.php, mainTest1.php   ← lógica real (no proxy)
    servidorREST/   conexion.php, ReglasREST.php

web_cliente/  (vacía por ahora)

Preparar:
1. XAMPP: Apache + MySQL
2. phpMyAdmin -> Importar bbdd/datosMediciones.sql
3. Copiar carpeta en htdocs, por ejemplo:
   C:\xampp\htdocs\biometria\servidor

Probar:
- GET  http://localhost/biometria/servidor/servidorREST/ReglasREST.php
- POST http://localhost/biometria/servidor/servidorREST/ReglasREST.php
  Body JSON ejemplo:
  {
    "nombre": "Mari-Biometria",
    "uuid": "EPSG-GTI-PROY-3A",
    "rssi": -53,
    "major": 2817,
    "minor": 123,
    "medicionCo2": 123,
    "id_sensor": 1
  }
